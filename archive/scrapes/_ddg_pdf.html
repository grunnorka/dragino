PS-CB-NA -- NB-IoT/LTE-M Analog Sensor - dragino.com

www.dragino.com/products/nb-iot/item/382-ps-cb-na.html     2026-06-24T00:00:00.0000000
The Dragino PS-CB-NA is a NB-IoT/LTE-M Analog Sensor for Internet of Things solution. PS-CB-NA has 5v and 12v output, 4~20mA, 0~30v input interface to power and get value from Analog Sensor. PS-CB-NA will convert the Analog Value to NB-IoT wireless data and send to IoT platform via NB-IoT/CAT-M1 network.
